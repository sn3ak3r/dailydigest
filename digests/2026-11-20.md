### CVE-2026-114938: Critical vulnerability in OpenJDK Java

**Problem:** "Java4Shell" (CVE-2026-114938, CVSS 9.2) lets an unauthenticated attacker run code on a Java server by sending it malformed Base64 text.

**Approach in plain words:** The bug affects OpenJDK 17.0.6 and later, but only on x86-64 CPUs with AVX-512 VBMI enabled. Intel and AMD both ship these chips widely, in data centres and in the cloud. Calif.io found it, and Talos confirmed it works against a range of Java apps.

**Result:** No in-the-wild exploitation yet. Patch now. Interim fix: start the JVM with `-XX:UseAVX=2`. This is x86 only, and ARM JVMs won't start with it. Snort rules flag malformed Base64 in HTTP fields.

**Why it matters:** Java servers decode Base64 constantly, so the attack surface is huge.

**Jargon:** *AVX-512 VBMI*: CPU vector byte-shuffle instructions. *RCE*: remote code execution. *CVSS*: severity score out of 10. *JVM*: Java virtual machine.
