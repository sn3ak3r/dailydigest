## Deep Digests

### 1. Gitea RCE: 8,300+ servers exposed, already under active exploitation

**Problem.** CVE-2026-60004 lets any registered user on a self-hosted Gitea (a popular self-hosted GitHub alternative) instance run arbitrary shell commands as the server's own service account.

**Approach.** Gitea's "diffpatch" feature, meant for applying patch files to a repo, can be abused to plant a malicious Git hook — a script Git runs automatically on certain repo actions. Since Gitea allows open self-registration by default, an attacker just signs up and creates a repo; no stolen credentials needed.

**Result.** Shadowserver scanned the internet on Aug 27 and found roughly 8,300 unpatched, exposed instances. CISA added the flaw to its actively-exploited catalog; federal agencies got a 3-day patch order. Attackers are already dropping cryptomining malware on compromised boxes.

**Why it matters.** If you run Gitea yourself, patch immediately and turn off open registration unless you truly need it — this isn't theoretical, it's being hit right now.

**Jargon:** *RCE* — running attacker-chosen commands on someone else's machine. *Git hook* — a script Git fires automatically on events like a push. *Diffpatch* — Gitea's endpoint for applying patch files to a repo. *CVE* — the standard ID assigned to a specific vulnerability.

### 2. Wikipedia on a Cheap Yellow Display

**Problem.** Getting a genuinely useful reference library onto a small, offline, dirt-cheap embedded board — no phone, no network, no subscription.

**Approach.** Developer Alun Morris runs a browser built for the ESP32 chip on the "Cheap Yellow Display" (CYD), a ~$15 dev board bundling an ESP32, a resistive touchscreen, and an SD card slot. Offline Wikipedia archives from the Kiwix project (images included) get repackaged into a compact format that fits on a plain SD card.

**Result.** A pocket-sized gadget that browses a full Wikipedia mirror with zero network connection.

**Why it matters.** It's a fun demonstration of how far commodity microcontrollers have come, and a real example of pushing knowledge out to the network's "edge" instead of leaning on the cloud.

**Jargon:** *ESP32* — a cheap microcontroller with built-in WiFi/Bluetooth. *Kiwix* — a project distributing offline copies of Wikipedia and similar sites. *Resistive touchscreen* — a touch display that senses physical pressure. *Edge computing* — running/storing data on the local device rather than a remote server.
