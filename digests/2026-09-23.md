### The Closed Quorum: Inside the First Reported Autonomous AI C2 Implant
[blog.talosintelligence.com](https://blog.talosintelligence.com/the-closed-quorum-inside-the-first-reported-autonomous-ai-c2-implant/)

Problem: Talos found CLOSEDQUORUM, the first Windows implant running an intrusion with no human deciding what happens next.
Approach: It asks four AI APIs (DeepSeek, Qwen, Mistral, Gemini) what to do, forces answers into a fixed menu, and acts on the plurality-vote winner; stolen credentials leave via encrypted Discord webhooks.
Result: The sample had placeholder API keys and never ran live, but static analysis confirmed the full loop, plus a "credentials-as-a-service" kit for customizing copies.
Why it matters: Attackers can hand tactical decisions to off-the-shelf LLMs; watch for multi-provider AI calls alongside process injection and LSASS access.
Glossary: LSASS - holds Windows login credentials. Process injection - running code in another program's memory. C2 - how malware is steered remotely.

### RHIC Data Reveal Intriguing Dip in Momentum Fluctuations in High-Density Nuclear Matter
[phys.org](https://phys.org/news/2026-09-rhic-reveal-intriguing-dip-momentum.html)

Problem: Physicists are hunting the nuclear "critical point," where dense matter's phase diagram changes character, like water's own critical point.
Approach: STAR, at Brookhaven's RHIC, collided gold ions across 3-200 GeV, measuring collision-by-collision spread in particle momentum as a stand-in for temperature fluctuations.
Result: Fluctuations fell as energy rose, hit a minimum near 5.2-7.7 GeV, then rose again - a 5-sigma dip breaking the smooth trend expected off a critical point.
Why it matters: Suppressed fluctuations there match critical-point predictions, but non-critical explanations aren't ruled out - a hint, not a discovery.
Glossary: Quark-gluon plasma - freed quarks/gluons from the early universe. Critical point - where transitions change character. Sigma - how unlikely a result is by chance.
