## Deep Digest: Microsoft patches LegacyHive Windows zero-day vulnerability

**Problem:** Windows' User Profile Service had a privilege-escalation hole — a normal user shouldn't become admin unassisted.

**Approach:** An attacker with a second local account edits the classes registry hive so it points somewhere it shouldn't ("link following"). When an admin next logs in, Windows resolves that link and runs the attacker's code with admin rights — no click needed.

**Result:** Any authenticated local user could escalate to admin. Microsoft patched it in August's Patch Tuesday as CVE-2026-62832.

**Why it matters:** It's one of several zero-days from the same researcher hitting Defender, BitLocker, and other core Windows pieces — worth watching for chained attacks.

**Glossary:** Privilege escalation, link following, registry hive, CVE.

## Deep Digest: Dissecting the JWR phishing framework

**Problem:** How do modern phishing-as-a-service kits actually work under the hood?

**Approach:** Talos reverse-engineered JWR, a live kit impersonating Shopify, PayPal, Apple, and Klarna checkouts. A script on the fake page opens a persistent WebSocket to the attacker's server, encrypted with AES-CTR, relaying commands into a Vue-based iframe that renders the phishing form.

**Result:** Victims' keystrokes stream to the operator live, letting a human react in real time. The kit harvests IDs, SSNs, 2FA codes, and device fingerprints via 40+ operator commands, and was pushed by SMS smishing across Southeast Asia and the Middle East.

**Why it matters:** Live, human-operated phishing beats static credential pages and slips past automated defenses built for the old kind.

**Glossary:** PhaaS, WebSocket, AES-CTR, smishing.
