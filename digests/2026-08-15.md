## Deep Digest: Critical VMware vCenter RCE flaw exploited for reverse SSH access

**Problem:** vCenter Server, VMware's central console for managing virtual infrastructure, had a critical directory-traversal bug in its Syslog Server component — letting an unauthenticated network attacker run code.

**Approach:** Attackers exploit the traversal flaw for initial access, then drop the open-source `reverse_ssh` tool to open an outbound tunnel home, slipping past firewalls built to block inbound connections.

**Result:** Broadcom patched vCenter 9.1/9.0/8.0 on August 3. Within five days, 343+ compromised IPs across dozens of countries were already seen, and the count kept climbing.

**Why it matters:** vCenter runs the infrastructure that runs everything else — one flaw here can cascade into every VM it manages.

**Glossary:** Directory traversal, RCE, reverse SSH, CVE.

## Deep Digest: Snooping Flume Water Monitor Data On The Wire

**Problem:** A hacker wanted to see what a Flume smart water monitor actually sends to the cloud — the device offers no local access to its own readings.

**Approach:** They pulled the unit's static secret key out of its flash memory, then built a man-in-the-middle relay that decrypts and re-forwards traffic between the bridge and Flume's servers, defeating the LibHydrogen encryption the device relies on.

**Result:** A working local logger for water-flow data, independent of the cloud, with the relay tool published for others to use.

**Why it matters:** Authenticating with one static, device-wide secret instead of rotating session keys means every unit is breakable the same way once a single key leaks.

**Glossary:** LibHydrogen, MITM, session key, static secret.
