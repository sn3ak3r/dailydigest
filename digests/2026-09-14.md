## Deep Digests

### Hackers exploit Tencent app flaw to deploy GrayRabbit malware

**Problem:** CVE-2026-51990, a one-click RCE flaw in Tencent's Sogou Input Method (huge China install base), exploited by China-aligned group UNC3569.

**Approach:** A crafted `sgbiz:` link passes unvalidated args to Sogou's helper, opening an outdated, unsandboxed Chromium webview at an attacker URL, which exploits a known browser bug for code execution.

**Result:** Installs a 64-bit GrayRabbit backdoor (reverse shells, file transfer, encrypted C2). Tencent patched the link handler in April; the browser stays outdated, unsandboxed.

**Why it matters:** Trusted software with link handlers becomes an RCE chain once each step trusts the last unchecked — one patch doesn't fix the rest.

**Glossary:** RCE (remote code execution) · URI handler (link protocol) · sandbox (code isolation) · C2 (attacker's control channel).

### Analyzing the FScale Instruction in Intel's 8087 FPU

**Problem:** How does the 8087, the coprocessor whose design shaped IEEE 754 float math, implement something as "simple" as FSCALE — scaling by a power of two?

**Approach:** Ken Shirriff reverse-engineered the 8087's microcode and die layout, tracing which circuit blocks fire when FSCALE runs.

**Result:** The "trivial" math takes 140+ micro-instructions across three subroutine levels, handling register loads, edge cases, errors, and stack management before returning an answer.

**Why it matters:** It reveals the hardware cost behind "basic" float math, and how the 8087's rigor became the template for IEEE 754, used by nearly every computer.

**Glossary:** microcode (hardware instructions for a CPU instruction) · FPU (floating-point unit) · IEEE 754 (float standard) · die shot (chip layout photo).
