### Custom Firmware for Fortinet FortiGate 60 Firewall/Router
https://hackaday.com/2026/11/17/custom-firmware-for-fortinet-fortigate-60-firewall-router/

**Problem:** A 2000s-era Fortinet FortiGate 60 firewall pulled from the trash only runs Fortinet's locked-down firmware.
**Approach:** Inside is a VIA C3 (400 MHz, x86) board, but its 128 MB of RAM is soldered on, and only the original firmware knew how to start it up. Matt Williams reverse-engineered that firmware to copy the RAM setup, then patched Linux 2.4 to boot.
**Result:** Linux runs, and so does DOOM on the framebuffer: green-only, because just the VGA green pin is connected.
**Why it matters:** Old enterprise gear dumped as e-waste can become a general-purpose retro PC when the firmware is reverse-engineered.
**Glossary:** *Firmware*: software built into the device. *SDRAM init*: setting the memory timings before RAM works. *Framebuffer*: simple direct-to-screen graphics. *VIA C3*: low-power x86 CPU.
