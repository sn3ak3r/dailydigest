### The Hidden Microcontroller Inside a LoRa chip
Problem: LoRa radio chips are treated as fixed-function parts, but Semtech's LR2021 hides an undocumented microcontroller. Approach: Alex Beal reverse engineered that MCU and its firmware interface (with LLM help), then wrote custom firmware loaded into the chip's RAM, so it vanishes on power-down. Result: custom code runs on the radio itself; on-chip FFTs for a waterfall display look feasible, and a host MCU could load it then sleep. Claims of a full mesh node are disputed in comments. Why it matters: turns a black-box transceiver into a programmable one, cutting host load and power. Glossary: LoRa (long-range low-power radio); MCU (microcontroller); FFT (time-to-frequency transform); SDR (radio functions in software).
