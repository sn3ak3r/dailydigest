## Deep digests

### Artifactory flaws chained in attacks deploying backdoor malware

**Problem:** JFrog Artifactory instances can be fully compromised via three chained flaws, even with anonymous access disabled.

**Approach:** Attackers first obtain a low-privilege JWT meant for an internal anonymous user (CVE-2026-42018). Weak token validation (CVE-2026-42016) lets them escalate that token to admin in minutes, and a third bug (CVE-2026-82329) allows minting admin tokens directly. From there they install malicious Groovy plugins to run commands.

**Result:** They drop a custom Rust-based backdoor with C2 capability, upload web shells, and add SSH keys for persistence. Multiple actors have exploited this chain since mid-August; roughly half of internet-reachable instances remain unpatched.

**Why it matters:** Artifactory sits inside software build pipelines — a compromised instance can poison downstream artifacts. Upgrade to 7.111.21+.

**Glossary:** JWT (signed login token), Groovy plugin (server-side script extension), C2 (attacker's remote command server), privilege escalation (gaining higher access than granted).

### Cisco FMC flaws exploited by ransomware gang, state-sponsored hackers

**Problem:** Cisco Secure Firewall Management Center had a maximum-severity (CVSS 10) authentication bypass plus a static-credential bug.

**Approach:** Chaining the two gives unauthenticated remote code execution as root. Attackers then abuse Cisco's own built-in tools for lateral movement — dropping web shells, opening SOCKS5 proxies and SSH tunnels, and modifying system files to blend in with normal operations.

**Result:** Three distinct clusters have used it: Qilin ransomware affiliates, a Russian state-linked group tied to Sandworm (which planted the Cyclops Blink backdoor), and one unattributed cluster.

**Why it matters:** FMC centrally manages fleets of firewalls, so one exploited box can expose an entire network. Cisco shipped emergency hotfixes, with full patches following.

**Glossary:** CVSS (vulnerability severity score, 0–10), auth bypass (skipping login checks), SOCKS5 proxy (traffic relay for hiding origin), backdoor (persistent covert access).
