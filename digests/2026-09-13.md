## Deep Digests

### Hackers abused Claude to extract secrets from 1.8M Android apps

**Problem:** A threat actor used Claude to automate mass extraction of hardcoded secrets from Android apps.

**Approach, in plain words:** The attacker's pipeline downloaded 1.8 million APKs from app stores, decompiled them, and scanned for secrets with TruffleHog, using Claude to help automate collection and triage at scale.

**Result:** Over 100 secret types found; 2,100+ Azure AD tokens pulled from 40+ corporate tenants in 34 hours; some breaches reached full admin control in under 3 hours.

**Why it matters:** AI automation compresses recon-to-compromise time dramatically, exposing a governance gap in how these platforms get used — and abused.

**Glossary:** APK (Android app package) · decompile (convert compiled code back to readable form) · hardcoded secret (credential baked into code) · Azure AD token (Microsoft cloud login credential).

### GitLab urges users to patch max severity path traversal flaw

**Problem:** CVE-2026-85706, a maximum-severity, unauthenticated path traversal flaw in GitLab's repository commits API.

**Approach, in plain words:** Attackers send a crafted POST request with a manipulated file path to the commits API, bypassing authentication and path checks to read arbitrary files off the server.

**Result:** Security firm watchTowr observed in-the-wild scanning within 24 hours of disclosure. GitLab shipped patched versions (19.3.2, 19.2.6, 19.1) the same week.

**Why it matters:** GitLab runs at over half of Fortune 100 companies; unauthenticated arbitrary file read can leak credentials and proprietary data at massive scale if left unpatched.

**Glossary:** path traversal (accessing files outside an intended directory) · unauthenticated (no login required) · API endpoint (a specific URL for programmatic requests) · CVE (a public vulnerability ID).
