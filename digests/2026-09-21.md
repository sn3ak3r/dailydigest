## Deep Digests

### Researchers Escape OpenAI Codex Sandbox to Run Commands on Host
[bleepingcomputer.com](https://www.bleepingcomputer.com/news/security/researchers-escape-openai-codex-sandbox-to-run-commands-on-host/)

Problem: OpenAI's Codex coding agent sandboxes untrusted code, but researchers found two ways out.
Approach: "Heapjack" abused node_repl, which runs trusted and untrusted JS in one process sharing one memory heap — attackers used V8's getHeapSnapshot() to read a validation token out of memory and reuse it to message the unsandboxed parent. "Overpatch" abused the CLI's apply_patch tool: naming /tmp in a patch widened write permissions via symlinks.
Result: Both worked even in Codex's most restrictive modes, achieving host code execution. OpenAI patched both within 8 days.
Why it matters: The enforcement logic lived inside the thing it was supposed to police — the same pattern turned up in Cursor and Gemini CLI.
Glossary: Sandbox - a restricted execution environment for untrusted code. Heap - a program's shared pool of dynamic memory. Symlink - a file that points to another path. Validation token - a secret string proving a request is authorized.

### Reviving TEMPEST Attacks with an Injected Signal
[hackaday.com](https://hackaday.com/2026/09/20/reviving-tempest-attacks-with-an-injected-signal/)

Problem: Classic TEMPEST eavesdropping reads a device's own stray radio emissions, but modern low-power electronics barely emit any.
Approach: The InjectEave technique instead transmits an RF signal tuned to a target's internal antennas; nonlinear parts inside (amplifiers, ADCs, switching MOSFETs) mix that signal with the device's internal data, radiating sidebands an attacker can demodulate with an SDR.
Result: With a USRP B210 SDR and spectrum analyzer, the team recovered headphone and VoIP audio and smart-device on/off states, up to 30m through walls with a power amp — enough audio, they note, to clone a voice.
Why it matters: It shows electromagnetic side-channel eavesdropping still works on "quiet" hardware, via an active attack that's harder to design against than passive TEMPEST.
Glossary: TEMPEST - eavesdropping via a device's unintended electromagnetic emissions. SDR - software-defined radio. Sideband - a frequency band created when two signals mix. Nonlinear component - a circuit part whose output isn't proportional to its input.
