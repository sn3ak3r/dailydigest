## Deep Digest 1: An Unauthenticated Hole Straight Through Your Router's Firewall

**Problem:** Calix GS7 XGS fiber gateways, deployed by ISPs like Cox and Brightspeed, expose a control service to the public internet with no login required.

**Approach, in plain words:** The router's UPnP service, meant only for devices inside the home to request port forwards, sits on the public WAN side instead of the LAN. Anyone online can send it raw requests to add or list port-forwarding rules.

**Result:** One unauthenticated request opens a permanent hole through the firewall to any device inside — cameras, NAS boxes, admin panels. The vendor never responded to disclosure, so CERT/CC published the flaw (CVE-2026-75501) unpatched.

**Why it matters:** No exploit skill needed, just the right port — and the model is deployed widely at major US broadband providers.

**Jargon glossary:**
- **NAT** — hides home devices behind one public IP.
- **UPnP** — lets home devices ask the router to open ports automatically.
- **WAN interface** — the router's internet-facing side.
- **CERT/CC** — Carnegie Mellon's vulnerability-disclosure coordination center.

## Deep Digest 2: Bridging Modern File Sharing to 20-Year-Old Macs

**Problem:** PowerPC Macs on OS X Tiger/Leopard predate SMB3, the protocol modern NAS boxes use, leaving them stuck on old, unencrypted SMB1/CIFS.

**Approach, in plain words:** Developer [watermark_hd] built Aqualink, using the open-source libsmb2 library to speak SMB2/3 on the Mac's behalf, then exposes those files locally over WebDAV — a protocol old OS X already mounts natively.

**Result:** These Macs can now mount modern SMB3 shares as ordinary network drives; source is on GitHub, though encrypted transport still isn't supported.

**Why it matters:** Rather than writing a new filesystem driver for a dead OS, translating one supported protocol into another keeps orphaned systems usefully networked.

**Jargon glossary:**
- **SMB3** — current Windows/NAS file-sharing protocol.
- **CIFS** — the older, insecure SMB1 predecessor.
- **WebDAV** — remote file access over plain HTTP.
- **libsmb2** — open-source SMB2/3 client/server library.
