## Deep digests

### BlackX UEFI bootkit exploits Baton Drop flaw to bypass Secure Boot
**Problem:** Secure Boot is meant to stop unsigned code running before Windows, yet BlackX bootkit compromised fully patched Windows machines at Central Asian diplomatic agencies (likely APT41, per Kaspersky).
**Approach:** It reuses BlackLotus's exploit of Baton Drop (CVE-2022-21894) to enroll its own trusted keys and load arbitrary EFI files, then loads a kernel driver signed with a revoked certificate that blinds security tools, tampers with ETW logging, and hides its files.
**Result:** Persistent RAT with cloud-storage C2 plus a Rust plugin loader.
**Why it matters:** The patch doesn't revoke the vulnerable "Windows Production PCA 2011" certificate automatically; admins must do it manually.
**Glossary:** *Bootkit* – malware running before the OS. *ETW* – Windows event tracing used by defenders. *MOK* – Machine Owner Key, user-trusted boot key. *C2* – attacker command channel.

### Supercurrent enables the reading of quantum information without destroying it
**Problem:** Reading a qubit directly collapses it; workarounds copy state to extra ancilla qubits, adding hardware and reset overhead.
**Approach:** Place an Andreev qubit (quantum dot in an InAs nanowire between superconductors) in a loop; its evolution drives an oscillating supercurrent, which a weakly coupled SQUID senses magnetically — no ancillas, no resets.
**Result:** Theory only (Phys. Rev. B): simulated accuracies of 99.52–99.85%, meeting error-correction thresholds; device not yet built.
**Why it matters:** Simpler readout could ease scaling quantum processors.
**Glossary:** *Ancilla* – helper qubit. *SQUID* – ultra-sensitive magnetometer. *Supercurrent* – resistance-free current. *Andreev state* – bound state at a superconductor interface.
