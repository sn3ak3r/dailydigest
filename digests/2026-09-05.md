## Deep Digests

### New CrowdStrike 'FalconFlank' zero-day grants SYSTEM privileges

**Problem:** CrowdStrike's Falcon endpoint-security agent — meant to stop attackers — has an unpatched Windows privilege-escalation bug.

**Approach:** Researcher "Nightmare Eclipse" found that Falcon's macro-remediation feature (auto-removes malicious Office macros) can be tricked into running attacker code with Falcon's own elevated permissions.

**Result:** On fully updated Windows 11 / Server 2025, the exploit pops a SYSTEM command prompt. No CVE yet; CrowdStrike is investigating and offers only a workaround. The same researcher dropped similar zero-days this week against Kaspersky, Avast, and Nvidia.

**Why it matters:** the tool trusted to catch privilege escalation is itself the escalation path, across several security vendors at once.

**Glossary:** EDR (endpoint detection & response agent); SYSTEM (Windows' highest privilege level); 0day (unpatched, disclosed vulnerability); PoC (proof-of-concept exploit code).

### Making a Pole Balance Itself With Propellers

**Problem:** balancing a pole on a fingertip is a classic trick; no hands makes it harder.

**Approach:** builder Peter Ryseck mounted a small drone (flight controller, battery, three propellers) atop a free-standing pole, using thrust to keep it upright like a self-stabilizing quadcopter.

**Result:** chasing perfect vertical balance caused wild oscillation, so Ryseck let the pole lean into the wind instead, a more stable configuration. Switching from 10-inch to 5-inch propellers cut inertia enough to react fast enough to stay up.

**Why it matters:** drone stabilization generalizes to non-flying balance problems, and "more stable" needn't mean "more upright."

**Glossary:** flight controller (board running the stabilization algorithm); active stabilization (continuously correcting orientation); inertia (resistance to rotation change); oscillation (unstable overcorrection loop).
