## Deep Digest: ClearFake WebDAV Infection Chain

**Problem:** Attackers need to plant stealer malware while dodging disk-based antivirus and EDR.

**Approach in plain words:** A fake CAPTCHA tricks the victim into running a command that loads a disguised DLL over WebDAV via `rundll32`, so nothing touches disk. One branch uses a blockchain contract as an unblockable dead-drop for its command server; the other uses a fixed server in Russia. Both abuse a vulnerable signed driver to kill security tools.

**Result:** Talos mapped two chains delivering crypto-theft malware (Amatera, ZigCryptoStealer) or a remote-access tool (NetSupport Manager).

**Why it matters:** Disk-based AV misses memory-only execution; watch for WebDAV-triggered `rundll32` calls and odd driver loads.

**Glossary:** WebDAV, BYOVD (abusing a vulnerable driver for kernel access), dead-drop resolver, ClickFix (fake-verification social engineering).

## Deep Digest: Decoding the NEC V20 Microcode ROM

**Problem:** A cycle-accurate emulator of the 1980s NEC V20 chip needs its real microcode, which exists only as ~30,000 bits baked into the physical die.

**Approach in plain words:** A hobbyist photographed the die and tried an existing bit-extraction tool, but low image contrast made it unreliable. So they trained a small neural network on about 1,000 hand-labeled bit images to classify each cell as 0 or 1, then manually checked the unclear ones.

**Result:** A largely-automated, published decode of the ROM, letting the V20's exact internal behavior be matched instruction by instruction.

**Why it matters:** Turns emulation from guesswork into a verified match to real silicon, and revisits the old NEC/Intel compatibility dispute.

**Glossary:** Microcode ROM (low-level instruction control logic), die shot (microscope photo of chip internals), cycle-accurate emulation (timing-exact simulation), CNN (image-classifying neural network).
