# Mini crackme: 2026-10-05

Windows x64 calling convention. `check(unsigned x)` receives `x` in ECX and returns 1 in AL if accepted.

```
check:
  bswap ecx
  xor   ecx, 0x3C3C3C3C
  cmp   ecx, 0x446A082E
  sete  al
  ret
```

What value of `x` makes `check` return 1?

---

**Answer: x = 0x12345678 (305419896)**

1. `bswap` reverses the four bytes of ECX (little-endian <-> big-endian swap), so the check is bswap(x) ^ 0x3C3C3C3C == 0x446A082E.
2. Undo in reverse order: 0x446A082E ^ 0x3C3C3C3C = 0x78563412 (XOR is self-inverse).
3. `bswap` is also its own inverse, so swapping 0x78563412 gives x = 0x12345678.
