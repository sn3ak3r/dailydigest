# Mini Crackme — 2026-09-05 (Windows x86-64)

`ecx` holds a 32-bit unsigned integer (Windows x64 calling convention,
first arg in `ecx`). Find the value of `ecx` that makes `check` return 1.

```asm
check:
    imul    eax, ecx, 0x1F   ; eax = x * 31
    and     eax, 0xFF        ; keep only the low byte of the product
    cmp     eax, 0x51        ; compare to target byte
    jne     fail
    mov     eax, 1
    ret
fail:
    xor     eax, eax
    ret
```

What value of `ecx` makes `check` return 1?

---

## Answer: `ecx = 0x8F` (143)

`imul eax, ecx, 0x1F` multiplies `x` by 31, and the `and eax, 0xFF`
throws away everything but the low 8 bits — so the check only depends on
`x mod 256`, not the full value.

Solving `(31 * x) mod 256 == 0x51` means finding 31's modular inverse mod
256, which is 223: multiplying both sides by 223 gives
`x ≡ 0x51 * 223 ≡ 143 (mod 256)`.

Passing `ecx = 143` (`0x8F`) makes `31 * 143 = 4433 = 0x1151`, whose low
byte is `0x51`, so the `cmp`/`jne` falls through and `check` returns 1.
