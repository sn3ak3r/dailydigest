# Crackme: find the input (Windows x64, arg in ecx)

```
    ror    ecx, 4
    xor    ecx, 0FFFFh
    xor    eax, eax
    cmp    ecx, 1234ABCDh
    sete   al
    ret
```

Which value of `ecx` makes the function return 1? Give it in hex.

---

**Answer:** `0x23454321`

1. `ror ecx, 4` rotates right: the low 4 bits wrap around into the top, so no bits are lost (unlike `shr`). Its inverse is `rol ecx, 4`.
2. The check needs `ror(ecx,4) ^ 0xFFFF == 0x1234ABCD`, so `ror(ecx,4) = 0x1234ABCD ^ 0xFFFF = 0x12345432`.
3. Undo the rotation with `rol 4`: `0x12345432` becomes `0x23454321`. The solution is unique, since xor and rotate are both bijections.
