# Reverse to C — 2026-08-22

Target: Windows x86-64, MSVC-style calling convention (`rcx` = arg1, `edx`/`edx`-sized = arg2). Reverse this function to equivalent C. `rcx` points to an `int` array; `edx` holds its element count.

```asm
find_min:
    mov     eax, [rcx]          ; eax = arr[0]
    mov     r8d, 1              ; r8d = i = 1
.loop:
    cmp     r8d, edx
    jge     .done
    mov     r9d, [rcx + r8*4]   ; r9d = arr[i]
    cmp     r9d, eax
    jge     .skip
    mov     eax, r9d            ; min = arr[i]
.skip:
    inc     r8d
    jmp     .loop
.done:
    ret
```

---

## Answer

```c
int find_min(int *arr, int count) {
    int min = arr[0];
    for (int i = 1; i < count; i++) {
        if (arr[i] < min) {
            min = arr[i];
        }
    }
    return min;
}
```

**Explanation:**
`eax` is seeded with `arr[0]` and doubles as both the loop's running minimum and the return value register, so no separate `min` variable needs a stack slot. The `[rcx + r8*4]` addressing mode is a scaled-index load — `r8` (the loop counter `i`) is multiplied by 4 (the size of an `int`) and added to the base pointer `rcx`, giving `arr[i]` without a separate multiply instruction. The `jge .skip` after each comparison is the inverted, negated form of `if (arr[i] < min)`: the branch is taken (skipping the update) whenever the condition is *false*, which is the standard way compilers turn a single `if` body into fall-through-on-true, branch-on-false control flow.
