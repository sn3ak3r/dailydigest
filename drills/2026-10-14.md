# Crackme drill: find the passing input

Windows x64, `ecx` holds your 32-bit integer argument. The function returns 1 for the correct input:

```
xor  eax, eax
bts  eax, ecx
cmp  eax, 100000h
sete al
ret
```

What is the smallest non-negative `ecx` that returns 1?

---

**Answer: 20** (52, 84, ... also work)

1. `xor eax, eax` zeroes eax; `bts eax, ecx` ("bit test and set") sets bit number ecx in eax, so eax = 1 << ecx.
2. 0x100000 = 2^20, so only bit 20 may be set, giving ecx = 20.
3. With a register operand the bit offset is taken mod 32, so any ecx congruent to 20 mod 32 also passes (52, 84, even -12).
