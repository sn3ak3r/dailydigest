# Decode One Instruction — 2026-08-18

Target: Windows x86-64, MSVC-compiled binary, function prologue.

Decode this raw byte sequence into its assembly instruction, and briefly
explain what each part of the encoding means:

```
48 83 EC 28
```

---

## Answer

```
sub rsp, 0x28
```

**Byte breakdown:**
- `48` — REX.W prefix. The REX prefix byte (`0100WRXB`) extends the
  legacy x86 encoding for 64-bit mode; the `W` bit set to 1 forces the
  operation to use a 64-bit operand size (`rsp` instead of `esp`).
- `83` — opcode for the Group 1 arithmetic instructions using a
  sign-extended 8-bit immediate. Which arithmetic operation it performs
  is not fixed by the opcode alone — it's selected by the ModRM `reg`
  field.
- `EC` — ModRM byte: `mod=11` (register-direct operand), `reg=101`
  (opcode extension `/5`, meaning SUB), `rm=100` (RSP). So this ModRM
  byte says "SUB, operand is RSP itself."
- `28` — the immediate operand, 0x28 (40 decimal), sign-extended to
  64 bits and subtracted from RSP.

This is a classic MSVC function prologue: it reserves 0x28 bytes of
stack space for locals and the shadow space required by the Windows
x64 calling convention.
