# Mini Crackme: x86-64 (Windows)

This is the first drill, so here's the minimum you need: `mov` copies a
value; `xor a, b` flips the bits of `a` wherever `b` has a 1 (XOR-ing the
same value twice restores the original); `cmp a, b` compares by
subtracting; `jne` jumps if the comparison wasn't equal; `eax` holds a
function's return value. On Windows x64, the first integer argument is
passed in `ecx`.

Find the 32-bit value that must be passed in `ecx` for `check` to return 1.

```asm
check:
    mov     eax, ecx
    xor     eax, 5Ah
    cmp     eax, 1Ah
    jne     fail
    mov     eax, 1
    ret
fail:
    xor     eax, eax
    ret
```

What value in `ecx` makes `check` return 1?

---

**Answer: `ecx = 0x40` (64 decimal)**

1. `eax` is loaded with `ecx`, then XOR'd with `0x5A`; the branch only
   avoids `fail` when that result equals `0x1A`.
2. So we need `ecx ^ 0x5A == 0x1A`. XOR is its own inverse, so
   `ecx = 0x1A ^ 0x5A = 0x40`.
3. With `ecx = 0x40`, `eax` becomes `0x1A`, the `cmp`/`jne` falls through,
   and `eax` is set to `1` before `ret`.
