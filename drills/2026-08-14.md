# Drill 2026-08-14 — mini crackme

Target: Windows x86-64 (Microsoft x64 calling convention: first integer
argument arrives in `ecx`).

Below is a disassembly of `check_serial(int x)`. Find the integer value of
`x` that makes it return 1 (success) instead of 0 (fail).

```asm
check_serial:
    mov     eax, ecx        ; eax = x
    imul    eax, eax, 3     ; eax = x * 3
    add     eax, 7          ; eax = x*3 + 7
    cmp     eax, 100        ; compare result to 100
    jne     fail
    mov     eax, 1          ; success
    ret
fail:
    xor     eax, eax        ; failure (eax = 0)
    ret
```

---

## Answer

**x = 31**

Explanation:
1. The function computes `x*3 + 7` in `eax`, then compares it against the
   constant `100` with `cmp`/`jne` — a mismatch jumps straight to `fail`.
2. Solving `3x + 7 = 100` gives `3x = 93`, so `x = 31`.
3. `mov eax, 1` only executes when the comparison falls through, matching
   the "return 1 = success" convention typical of these check functions.
