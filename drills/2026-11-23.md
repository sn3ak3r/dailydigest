# Crackme: find the number (Windows x64, arg in ecx)

`ecx` holds an unsigned 32-bit number.

```
check:
    mov    eax, ecx      ; eax = copy of x
    shr    eax, 1        ; eax = x >> 1 (shift right, top bit filled with 0)
    xor    eax, ecx      ; eax = (x >> 1) ^ x
    cmp    eax, 0Fh
    jne    fail
    mov    eax, 1
    ret
fail:
    xor    eax, eax
    ret
```

What value of `x` makes `check` return 1?

Hint: this one is not a simple "undo each step backwards". The xor mixes `x` with a shifted copy of *itself*, so work in binary, one bit at a time, starting from the top.

---

**Answer:** `x = 10` (0b1010)

1. Each result bit is `x[i] ^ x[i+1]`, i.e. the bit XORed with its left-hand neighbour. The top bit has a 0 to its left (shr fills with 0), so it passes through unchanged.
2. Target 0b1111: every bit above bit 3 is 0, so x has nothing above bit 3, and bit 3 = 1. Moving down, each next bit = the result bit XOR the x bit just above it: 1^1=0, 1^0=1, 1^1=0, giving 1010.
3. Check: 1010 ^ 0101 = 1111 = 0Fh. (`x ^ (x >> 1)` is the "Gray code" of x, and the answer is unique.)
