# Reverse-a-function drill — 2026-10-22

Target: Windows x86-64 (first arg in `ecx`; return in `eax`).

Reverse this short function to equivalent C:

```asm
mystery:
    mov     eax, ecx
    cdq
    and     edx, 7
    add     eax, edx
    sar     eax, 3
    ret
```

What does `mystery(-9)` return, and why not just a bare `sar eax, 3`?

---

## Answer

```c
int mystery(int x) {
    return x / 8;
}
```

`mystery(-9)` returns `-1` (a bare `sar` would give `-2`).

## Explanation

- `cdq` copies the sign bit of `eax` into all of `edx` (0 or -1); `and edx, 7` turns that into a bias of 0 (x >= 0) or 7 (x < 0).
- `sar` alone rounds toward negative infinity (floor), but C division truncates toward zero; adding 2^n - 1 to negatives first fixes this: (-9 + 7) >> 3 = -1.
- Signed divide by a power of two compiles to this bias + `sar` instead of a slow `idiv`; an unsigned divide would just be `shr`.
