# Reverse-a-function drill — 2026-10-10

Target: Windows x86-64 (arg in `ecx`, return in `al`/`eax`).

Reverse this short function to equivalent C:

```asm
mystery:
    sub     ecx, 48
    xor     eax, eax
    cmp     ecx, 9
    setbe   al
    ret
```

What does `mystery(int c)` compute? Why is there only one comparison, and why `setbe` rather than `setle`?

---

## Answer

```c
int mystery(int c) {
    return (unsigned)(c - '0') <= 9;   // isdigit-style range check
}
```

## Explanation

- 48 is `'0'`; subtracting it maps `'0'..'9'` to `0..9`, and anything below `'0'` wraps to a huge unsigned value.
- `setbe` (CF=1 or ZF=1) is an *unsigned* compare, so one `cmp` rejects both too-small and too-large inputs, replacing `c >= '0' && c <= '9'`.
- `xor eax,eax` comes before `cmp` because xor would clobber the flags; `setbe` writes only `al`, so the upper bits stay 0.
