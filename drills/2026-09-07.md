# 2026-09-07 — Reverse a Short Function to C

Target: Windows x86-64. `n` arrives in `ecx` (first int arg), result returned in `eax`.

```asm
sum_digits:
    xor   r9d, r9d
.loop:
    test  ecx, ecx
    jz    .done
    mov   eax, ecx
    cdq
    mov   r8d, 10
    idiv  r8d
    add   r9d, edx
    mov   ecx, eax
    jmp   .loop
.done:
    mov   eax, r9d
    ret
```

What does this function compute? Write the equivalent C.

---

## Answer

```c
int sum_digits(int n) {
    int sum = 0;
    while (n != 0) {
        int q = n / 10;
        int r = n % 10;
        sum += r;
        n = q;
    }
    return sum;
}
```

**Explanation:**
1. `cdq` sign-extends `ecx` into `edx:eax` so `idiv r8d` performs a proper signed 32-bit division by 10, leaving the quotient in `eax` and the remainder in `edx`.
2. Each pass adds the remainder (least-significant decimal digit) into the running total `r9d`, then feeds the quotient back into `ecx` for the next iteration.
3. `test ecx, ecx` / `jz .done` is the standard zero-test loop guard, so the loop runs once per decimal digit of `n` and returns their sum.
