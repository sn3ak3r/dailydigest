# Reverse-a-function drill — 2026-10-28

Target: Windows x86-64 (arg in `ecx`).

Reverse this short function to equivalent C:

```asm
mystery:
    lea     eax, [rcx-48]
    cmp     eax, 9
    setbe   al
    movzx   eax, al
    ret
```

There is only one comparison and no `&&`. What does it compute, and why does it work?

---

## Answer

```c
int mystery(int c) {
    return c >= '0' && c <= '9';   // isdigit for ASCII
}
```

## Explanation

- `lea eax,[rcx-48]` is just a subtract (48 = `'0'`) that leaves flags alone; `c` in `'0'..'9'` becomes 0..9.
- `setbe` is an *unsigned* test (CF=1 or ZF=1): any `c < 48` wraps to a huge unsigned value (e.g. 47 → 0xFFFFFFFF), so it fails `<= 9` too.
- One unsigned compare thus checks both bounds: `(unsigned)(c - lo) <= (hi - lo)` is the standard compiler range-check trick.
