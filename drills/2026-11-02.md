# Crackme: find the input (Windows x64, arg in ecx)

```
    lea    eax, [rcx+rcx*4]
    neg    eax
    add    eax, 100
    cmp    eax, -50
    sete   al
    movzx  eax, al
    ret
```

Which value of `ecx` makes the function return 1? Give it in decimal.

---

**Answer:** `30` (0x1E)

1. `lea eax,[rcx+rcx*4]` computes `ecx*5` with no flags touched; `neg` then gives `-5*ecx` (two's complement: invert and add 1).
2. The check needs `-5*ecx + 100 == -50`, so `-5*ecx = -150`.
3. Dividing by -5 gives `ecx = 30`. Check: 150, negated -150, plus 100 is -50. The solution is unique modulo 2^32, because 5 is odd and so invertible.
