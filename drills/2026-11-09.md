# Decode-one-instruction drill — 2026-11-09

Target: Windows x86-64.

Decode this instruction, located at address `0x140001000`:

```
FF 15 F2 0F 00 00
```

What is the assembly? Where in memory is the pointer it reads, and what kind of call is this (direct or indirect)?

---

## Answer

`call qword ptr [rip+0xFF2]` — an indirect call through the pointer stored at `0x140001FF8`.

- `FF /2` is CALL r/m64 (near indirect). ModRM `15` = `00 010 101`: reg=010 is the /2 opcode extension (/0 would be INC), mod=00 with rm=101 means RIP-relative disp32. No REX needed; operand size is 64-bit by default.
- Disp32 `F2 0F 00 00` is little-endian 0x00000FF2. RIP is the next instruction (0x140001000 + 6 = 0x140001006), so the pointer lives at 0x140001006 + 0xFF2 = 0x140001FF8.
- This is the usual Windows import call: that slot is an Import Address Table entry, and the CPU loads the API address from it and calls it (unlike E8, the target isn't encoded in the instruction).
