# Reverse a Short Function to C

Target: Windows x86-64. `rcx` = `long long *arr`, `edx` = `int count` (Microsoft x64 calling convention). Reverse this function to equivalent C.

```asm
func:
    xor   eax, eax        ; sum = 0
    test  edx, edx
    jle   done
loop_top:
    mov   r8, [rcx]
    test  r8, r8
    js    skip
    add   rax, r8
skip:
    add   rcx, 8
    dec   edx
    jnz   loop_top
done:
    ret
```

What does this function compute, and what does it return in `rax`?

---

## Answer

```c
long long sum_positive(long long *arr, int count) {
    long long sum = 0;
    for (int i = 0; i < count; i++) {
        if (arr[i] >= 0) {
            sum += arr[i];
        }
    }
    return sum;
}
```

**Explanation:**
`rax` accumulates the sum, seeded to zero, with an early `jle` bailout when `count <= 0`. Each iteration loads one 8-byte element through `rcx` (advanced by `add rcx, 8`, i.e. `arr[i]`), and `test r8, r8` / `js skip` uses the sign flag to skip negative elements without a real comparison. `dec edx` / `jnz` counts `count` down to zero, so the loop runs exactly `count` times regardless of how many elements were skipped.
