# Drill: Reverse to C — 2026-09-04

Target: Windows x86-64 (MSVC calling convention: `ecx` = arg1).

Reverse this disassembly to equivalent C:

```asm
func:
    xor     eax, eax        ; eax = 0
    test    ecx, ecx
    jz      done
loop_top:
    mov     edx, ecx
    and     edx, 1
    add     eax, edx
    shr     ecx, 1
    test    ecx, ecx
    jnz     loop_top
done:
    ret
```

What does `func(unsigned int n)` compute, and what does it return?

---

## Answer

```c
int func(unsigned int n) {
    int count = 0;
    while (n != 0) {
        count += n & 1;
        n >>= 1;
    }
    return count;
}
```

- `and edx, 1` isolates the current low bit of `ecx` (a copy of `n`) and `add eax, edx` folds it into the running total — this is a bit-population-count (`popcount`) accumulator, not a comparison or arithmetic check.
- `shr ecx, 1` shifts `n` right one bit per iteration, discarding the bit just tested, so successive passes examine each bit from least- to most-significant.
- `test ecx, ecx` / `jnz loop_top` re-tests the shifted value each pass, terminating once all set bits have been consumed and `ecx` reaches zero — the initial `test ecx, ecx` / `jz done` is the same check applied up front for `n == 0`.
