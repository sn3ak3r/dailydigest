# Mini crackme: 2026-09-29

Windows x64 calling convention. `check(int x)` receives `x` in ECX and returns 1 in AL if the input is accepted:

```
check:
  lea  eax, [rcx+rcx*2]
  shl  eax, 2
  sub  eax, 5
  cmp  eax, 0x1F3
  sete al
  ret
```

What value of `x` makes `check` return 1?

---

**Answer: x = 42**

1. `lea eax,[rcx+rcx*2]` is just arithmetic (no memory access): eax = x + 2x = 3x. `shl eax,2` multiplies by 4, giving 12x; `sub eax,5` gives 12x - 5.
2. `0x1F3` = 499, so the check is 12x - 5 = 499.
3. Solving: 12x = 504, so x = 42 (unique, since 12x-5 is one-to-one).
