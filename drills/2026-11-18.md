# Decode-one-instruction drill — 2026-11-18

Target: Windows x86-64.

A function takes two 64-bit integers (`rcx`, `rdx`). After `mov rax, rcx`, the next instruction is:

```
48 0F AF C2
```

What is the assembly, which register gets the result, and how does it differ from the one-operand `mul` you saw on 11-07?

---

## Answer

`imul rax, rdx` — `rax = rax * rdx`, keeping only the low 64 bits. With the `mov`, the function is `return a * b;`.

- `48` is REX.W (64-bit operands). `0F AF /r` is the two-byte opcode for two-operand IMUL r, r/m: the reg field is the destination and also the first factor.
- ModRM `C2` = `11 000 010`: mod=11 means register-direct, reg=000 = rax (destination), rm=010 = rdx (source).
- Unlike `mul`, nothing is written to `rdx`: the high half is thrown away, and you can choose any destination register. The low 64 bits are the same for signed and unsigned inputs, so compilers emit `imul` for every plain `a * b`.
