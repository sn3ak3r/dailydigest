# Drill 2026-09-20 — Mini Crackme (Windows x86-64)

`check_password` takes a 4-byte ASCII string in `rcx` (Windows x64: first
arg in `rcx`). Find an input that makes it return 1.

```asm
check_password PROC
    lea  r9, target                ; r9 -> expected cipher bytes
    xor  r8d, r8d                  ; i = 0
.top:
    cmp  r8d, 4
    jge  .pass
    movzx edx, byte ptr [rcx+r8]   ; edx = input[i]
    add  edx, 3                    ; Caesar shift +3
    cmp  edx, 'Z'
    jle  .store
    sub  edx, 26                   ; wrap past 'Z' back toward 'A'
.store:
    cmp  dl, byte ptr [r9+r8]
    jne  .fail
    inc  r8d
    jmp  .top
.pass:
    mov  eax, 1
    ret
.fail:
    xor  eax, eax
    ret
target byte "ZABC"
check_password ENDP
```

What 4-character string passes the check?

---

## Answer

**`WXYZ`**

- Each byte is Caesar-shifted `+3`; `cmp edx,'Z' / jle` decides whether the
  shifted value stays in range or wraps by subtracting 26 (mod-26 alphabet
  wraparound), then it's compared against `target = "ZABC"` via indexed
  pointer `[r9+r8]`.
- To invert, subtract 3 from each target byte and add 26 back whenever
  the result underflows below `'A'`: `Z-3='W'`, `A-3` wraps to `'X'`,
  `B-3` wraps to `'Y'`, `C-3` wraps to `'Z'`.
- That gives input `WXYZ`, which the forward shift turns into `ZABC`,
  matching the target and returning `eax=1`.
