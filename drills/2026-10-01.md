# Reverse-a-function drill — 2026-10-01

Target: Windows x86-64 (MSVC convention: args in `ecx`, `edx`, `r8d`; return in `eax`).

Reverse this short function to equivalent C:

```asm
mystery:
    mov     eax, ecx
    cmp     eax, edx
    cmovl   eax, edx
    cmp     eax, r8d
    cmovg   eax, r8d
    ret
```

What does `mystery(int x, int lo, int hi)` return?

---

## Answer

```c
int mystery(int x, int lo, int hi) {
    if (x < lo) x = lo;
    if (x > hi) x = hi;
    return x;
}
```

It clamps `x` into the range `[lo, hi]` (if `lo > hi`, it returns `hi`).

## Explanation

- `cmovl`/`cmovg` copy the source into `eax` only if the signed condition from the preceding `cmp` holds — a branchless `if`, with no jumps.
- First pair: `cmp eax, edx` then `cmovl` raises `x` to `lo` when `x < lo`.
- Second pair: `cmp eax, r8d` then `cmovg` lowers the result to `hi` when it exceeds `hi`; `l`/`g` mean signed compares.
