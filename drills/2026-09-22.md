# Reverse to C — 2026-09-22

Target: Windows x86-64 (MSVC calling convention: RCX = arg1, EDX = arg2).
Reverse this function to equivalent C.

```asm
sum_sq:
        push    rbp
        mov     rbp, rsp
        xor     eax, eax          ; total = 0
        xor     r8d, r8d          ; i = 0
.loop:
        cmp     r8d, edx
        jge     .done
        movsxd  r9, dword ptr [rcx + r8*4]
        imul    r9, r9
        add     rax, r9
        inc     r8d
        jmp     .loop
.done:
        pop     rbp
        ret
```

What does `sum_sq` compute, and what are its parameter types?

---

## Answer

```c
long long sum_sq(int *arr, int count) {
    long long total = 0;
    for (int i = 0; i < count; i++) {
        long long v = arr[i];   // movsxd sign-extends the 32-bit element
        total += v * v;
    }
    return total;
}
```

- `push rbp` / `mov rbp, rsp` / `pop rbp` is a standard stack-frame prologue and epilogue; this function has no locals or callees, so RBP is only saved/restored, never dereferenced.
- `movsxd r9, [rcx + r8*4]` reads a 32-bit `int` at scaled index `i` and sign-extends it into a 64-bit register before squaring, matching `arr[i]` widened to `long long`.
- `cmp r8d, edx` / `jge .done` is the loop guard (`i < count`), and RAX (return register) accumulates the running sum of squares.
