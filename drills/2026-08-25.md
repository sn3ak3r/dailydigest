# Drill: 2026-08-25 — Reverse a Short Function to C

Target: Windows x86-64 (fastcall: first `int` arg in `ecx`; return in `eax`).

Reverse this disassembly to equivalent C:

```asm
foo:
    mov     eax, ecx
    and     eax, 8
    setne   al
    movzx   eax, al
    ret
```

What does `foo(int x)` compute?

---

## Answer

```c
int foo(int x) {
    return (x & 8) != 0;
}
```

**Explanation:**
1. `and eax, 8` clears every bit of `x` except bit 3, leaving either `0` (bit was clear) or `8` (bit was set), and sets `ZF` from that result.
2. `setne al` writes `1` into the low byte `al` if `ZF` is clear (the `and` was nonzero) or `0` if `ZF` is set — turning the flag test into a boolean value without a branch.
3. `movzx eax, al` zero-extends that single byte up to the full 32-bit `eax`, which is the ABI's return register, so stray high bits from the earlier `and` never leak into the result.
