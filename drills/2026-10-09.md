# Decode-one-instruction drill — 2026-10-09

Target: Windows x86-64.

This instruction sits at address `0x140001010`:

```
E8 EB FF FF FF
```

What is the assembly? What address does it call, and what does it push on the stack?

---

## Answer

`call 0x140001000` (pushes return address `0x140001015`)

- `E8` = `CALL rel32`; the operand `EBFFFFFF` is little-endian 0xFFFFFFEB = -0x15 (signed 32-bit).
- Displacement is relative to the *next* instruction: 0x140001010 + 5 (length) = 0x140001015, then 0x140001015 − 0x15 = 0x140001000. A negative displacement means a backward call.
- CALL pushes that next-instruction address (rsp -= 8), which `ret` later pops; no REX or ModRM byte is needed.
