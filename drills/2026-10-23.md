# Crackme: find the input (Windows x64, arg in ecx)

```
    mov    eax, ecx
    xor    edx, edx
    mov    r8d, 13
    div    r8d
    cmp    edx, 5
    jne    fail
    cmp    eax, 1000
    sete   al
    movzx  eax, al
    ret
fail:
    xor    eax, eax
    ret
```

Which value of `ecx` makes the function return 1? Give it in decimal.

---

**Answer:** `13005`

1. `div r8d` is unsigned: it divides `edx:eax` by r8d, so `edx` must be zeroed first (`xor edx, edx`). The quotient lands in `eax`, the remainder in `edx`.
2. The checks demand remainder 5 (`cmp edx, 5`) and quotient 1000 (`cmp eax, 1000`).
3. Invert the division: `ecx = quotient * 13 + remainder = 1000*13 + 5 = 13005`. It is the only solution, since quotient and remainder fix the dividend uniquely.
