# Drill: 2026-08-28 — Reverse a Short Function to C

Target: Windows x86-64 (fastcall: first `int` arg in `ecx`; return in `eax`).

Reverse this disassembly to equivalent C:

```asm
foo:
    mov     eax, ecx
    sar     eax, 31
    xor     ecx, eax
    sub     ecx, eax
    mov     eax, ecx
    ret
```

What does `foo(int x)` compute?

---

## Answer

```c
int foo(int x) {
    return x < 0 ? -x : x;
}
```

**Explanation:**
1. `sar eax, 31` arithmetic-shifts the sign bit across all 32 positions, turning `eax` into an all-ones mask (`0xFFFFFFFF`) when `x` is negative, or all-zeros when `x` is non-negative.
2. `xor ecx, eax` is a no-op when the mask is zero, but when the mask is all-ones it flips every bit of `x`, i.e. computes `~x`.
3. `sub ecx, eax` then subtracts the mask: subtracting `0` leaves `x` unchanged; subtracting `-1` (all-ones, as a signed value) is the same as adding `1`, so `~x` becomes `~x + 1 = -x` — the classic branchless `abs()` idiom using two's-complement negation.
