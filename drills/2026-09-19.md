# Reverse a Short Function to C

Target: Windows x86-64. `rcx` = `Node *head` (Microsoft x64 calling
convention). Assume `struct Node { Node *next; int val; };` so `next` sits
at offset 0. Reverse this function to equivalent C.

```asm
func:
    xor   eax, eax
loop:
    test  rcx, rcx
    je    done
    inc   eax
    mov   rcx, [rcx]
    jmp   loop
done:
    ret
```

What does this function compute, and what does it return in `eax`?

---

## Answer

```c
int count_nodes(Node *head) {
    int count = 0;
    while (head != NULL) {
        count++;
        head = head->next;
    }
    return count;
}
```

**Explanation:**
`eax` starts at zero and the loop tests `rcx` (the current node pointer)
against zero each iteration, exiting via `je done` once the list ends.
While the pointer is non-null, `inc eax` tallies one more node and
`mov rcx, [rcx]` dereferences the pointer to load `next` (offset 0),
advancing to the following node. This is a pointer-chasing linked-list
traversal that counts its nodes, returning the length in `eax`.
