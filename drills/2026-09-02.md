# Mini Crackme — 2026-09-02 (Windows x86-64)

`ecx` holds a 32-bit signed integer (Windows x64 calling convention, first
arg in `ecx`). Find the value of `ecx` that makes `check` return 1.

```asm
check:
    mov     eax, ecx
    sub     eax, 777      ; eax = x - 777
    neg     eax           ; eax = -(x - 777) = 777 - x
    cmp     eax, 1000
    jne     fail
    mov     eax, 1
    ret
fail:
    xor     eax, eax
    ret
```

What value of `ecx` makes `check` return 1?

---

## Answer: `ecx = -223` (`0xFFFFFF21`)

`neg` computes the two's-complement negation of its operand — it's
equivalent to `0 - eax`, so after `sub eax, 777` (giving `x - 777`), the
`neg` turns that into `777 - x`.

The `cmp`/`jne` pair requires `777 - x == 1000`, so solving backward gives
`x = 777 - 1000 = -223`.

Passing `ecx = -223` makes `eax` land on exactly `1000` after the `sub`/`neg`
pair, so the `jne` falls through and `check` returns 1.
