# Decode One Instruction — 2026-09-27

Target: Windows x86-64.

At address `0x140001008`, the disassembler shows these raw bytes:

```
0F 84 12 34 00 00
```

Decode this instruction: name it, state its operand encoding, and compute
the branch target address it jumps to.

---

## Answer

**`je 0x140004420`** (aka `jz`) — near conditional jump, rel32 form.

- `0F 84` is the two-byte opcode for `JE/JZ rel32`. The `0F` escape byte is
  what distinguishes the *near* (32-bit displacement) conditional jumps from
  the *short* form (single-byte opcode `0x74`, 8-bit displacement) — this
  variant is needed whenever the branch target is too far for a signed
  8-bit offset to reach.
- The remaining 4 bytes `12 34 00 00` are the little-endian signed
  displacement: `0x00003412` = `13330`.
- x86 branch displacements are relative to the *next* instruction, not the
  jump itself: next-instruction address = `0x140001008 + 6` (instruction
  length) = `0x14000100E`. Target = `0x14000100E + 0x3412` = `0x140004420`.
