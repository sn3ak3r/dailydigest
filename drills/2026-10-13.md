# Reverse-a-function drill — 2026-10-13

Target: Windows x86-64 (arg in `ecx`, return in `eax`).

Reverse this short function to equivalent C:

```asm
mystery:
    neg     ecx
    sbb     eax, eax
    neg     eax
    ret
```

What does `mystery(int x)` compute? Where does the carry flag come from, and what does `sbb eax, eax` do?

---

## Answer

```c
int mystery(int x) {
    return x != 0;   // branchless boolean normalize
}
```

## Explanation

- `neg ecx` computes 0 - ecx; it sets CF=1 for any nonzero input and CF=0 only when ecx is 0.
- `sbb eax, eax` is eax - eax - CF, so eax = -CF: all ones (-1) if x was nonzero, else 0 — a full-width mask built from a single flag.
- The final `neg eax` turns -1 into 1, giving 0 or 1 with no branch, no `setne`, and no `xor` zeroing needed.
