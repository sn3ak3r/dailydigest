# Reverse a Short Function to C

Target: Windows x86-64. `rcx` = `const char *s` (Microsoft x64 calling
convention). Reverse this function to equivalent C.

```asm
func:
    mov   rax, rcx
scan:
    cmp   byte ptr [rax], 0
    je    done
    inc   rax
    jmp   scan
done:
    sub   rax, rcx
    ret
```

What does this function compute, and what does it return in `rax`?

---

## Answer

```c
size_t my_strlen(const char *s) {
    const char *p = s;
    while (*p != 0) {
        p++;
    }
    return p - s;
}
```

**Explanation:**
`rax` is initialized to a copy of the string pointer and walks forward one
byte at a time (`inc rax`), comparing each byte against zero until it hits
the null terminator (`je done`). Once the loop exits, `sub rax, rcx`
computes the distance traveled — the scanning pointer minus the original
pointer still held in `rcx` — which is exactly the string's length, so this
is a straightforward hand-rolled `strlen`.
