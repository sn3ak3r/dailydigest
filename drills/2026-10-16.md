# Reverse-a-function drill — 2026-10-16

Target: Windows x86-64 (args in `ecx`, `edx`; return in `eax`).

Reverse this short function to equivalent C:

```asm
mystery:
    lea     eax, [rcx+rcx*2]
    lea     eax, [rdx+rax*4+7]
    ret
```

What does `mystery(int a, int b)` compute? No `imul`, `add` or `shl` appears, so where is the arithmetic happening?

---

## Answer

```c
int mystery(int a, int b) {
    return 12 * a + b + 7;
}
```

## Explanation

- `lea` runs the address-generation math `base + index*scale + disp` (scale 1/2/4/8) but never touches memory, so it works as a cheap multiply-add.
- First `lea`: a + a*2 = 3a. Second: b + (3a)*4 + 7 = 12a + b + 7, three terms folded into one instruction.
- Unlike `add`/`imul`, `lea` leaves the flags unchanged, which is why compilers love it; the 32-bit destination zero-extends into rax.
