# Decode One Instruction (Windows x86-64)

Decode this 4-byte sequence into a full x86-64 instruction (name it, and state every operand):

```
40 0F 95 C6
```

---

## Answer

`setne sil`

- `40` is a REX prefix with no W/R/X/B bits set. Alone it changes nothing about register width or extension, but for byte operands it does one thing: it makes the low-byte registers `sil/dil/bpl/spl` available instead of the legacy high-byte registers `ah/ch/dh/bh`.
- `0F 95` is the opcode for `SETNE r/m8` (set byte to 1 if ZF=0, else 0). The `ModRM` byte `C6` = `11 000 110`: `mod=11` selects register-direct addressing, `reg=000` is just an opcode-extension bit pattern (ignored for `SETcc`), and `rm=110` picks register index 6.
- Without the REX prefix, register index 6 in a byte operand means `dh`. Because a REX prefix is present, it instead means `sil` (low byte of `rsi`) — so the full instruction is "set `sil` to 1 if the last comparison's zero flag is clear."
