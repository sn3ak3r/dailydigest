# Mini Crackme — 2026-09-11 (Windows x86-64)

`rcx` points to a 4-byte ASCII buffer (Windows x64 calling convention,
first arg in `rcx`). Find a 4-character string that makes `check`
return 1.

```asm
check:
    xor     eax, eax           ; sum = 0
    xor     edx, edx           ; i = 0
.loop:
    movzx   r8d, byte [rcx+rdx]
    add     eax, r8d           ; sum += buf[i]
    inc     edx
    cmp     edx, 4
    jl      .loop
    cmp     eax, 394           ; compare to target sum
    jne     fail
    mov     eax, 1
    ret
fail:
    xor     eax, eax
    ret
```

What 4-character string makes `check` return 1?

---

## Answer: `"abcd"`

The loop walks the 4 bytes at `[rcx]` with `movzx`/`add`, accumulating
their raw ASCII values into `eax` — no shifting or weighting, just a
plain running total, then `inc edx`/`cmp edx,4`/`jl` repeats it exactly
four times.

After the loop, `cmp eax, 394` / `jne fail` demands the four bytes sum
to exactly 394; any input can pass as long as its ASCII values add up
to that constant.

`'a'+'b'+'c'+'d' = 97+98+99+100 = 394`, so `"abcd"` clears the check
and `check` returns 1 (many other 4-byte combinations summing to 394
would also work).
