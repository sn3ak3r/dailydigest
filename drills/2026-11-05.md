# Crackme: find the input (Windows x64, arg in ecx)

```
    imul   eax, ecx, 13
    add    eax, 7
    cmp    eax, 150
    sete   al
    movzx  eax, al
    ret
```

Which value of `ecx` makes the function return 1? Give it in decimal.

---

**Answer:** `11` (0xB)

1. `imul eax, ecx, 13` is the three-operand form (opcode 6B /r for imm8): dest = src * immediate, so the source `ecx` is not overwritten. Only the low 32 bits of the product are kept.
2. The check needs `13*ecx + 7 == 150`, so `13*ecx = 143`.
3. Dividing gives `ecx = 11`. Check: 143 + 7 = 150. Since 13 is odd it is invertible mod 2^32, so 11 is the only 32-bit solution.
