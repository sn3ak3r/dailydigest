# Decode-one-instruction drill — 2026-10-15

Target: Windows x86-64.

Decode this instruction:

```
48 FF 45 F8
```

What is the assembly? What does it do to memory, and where exactly?

---

## Answer

`inc qword ptr [rbp-8]`

- `48` = REX.W (64-bit operand size). `FF` is the "group 5" opcode; the ModRM reg field is an extension: /0 = INC, /1 = DEC (/2 = call, /4 = jmp, /6 = push).
- ModRM `45` = `01 000 101`: mod=01 (disp8 follows), reg=000 (/0 = INC), rm=101 (rbp as base).
- `F8` is the signed disp8 = -8, so the 8-byte value at rbp-8 is incremented in place (read-modify-write, no register loaded).
