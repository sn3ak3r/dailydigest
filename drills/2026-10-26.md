# Crackme: find the input (Windows x64, arg in ecx)

```
    mov    eax, ecx
    bswap  eax
    xor    eax, 0FFh
    cmp    eax, 123456AAh
    sete   al
    movzx  eax, al
    ret
```

Which value of `ecx` makes the function return 1? Give it in decimal (and hex).

---

**Answer:** `1431712786` (`0x55563412`)

1. `bswap eax` reverses the four bytes (endianness swap): `0xAABBCCDD` becomes `0xDDCCBBAA`. It is its own inverse.
2. The check needs `bswap(ecx) ^ 0xFF == 0x123456AA`, so `bswap(ecx) = 0x123456AA ^ 0xFF = 0x12345655`.
3. Undo the swap by reversing the bytes again: `ecx = 0x55563412`. The solution is unique, since both xor and bswap are bijections.
