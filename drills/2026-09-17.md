# Drill 2026-09-17 — Mini Crackme (Windows x86-64)

`check_password` takes a 4-byte ASCII string in `rcx` (Windows x64: first
arg in `rcx`). Find an input that makes it return 1.

```asm
check_password PROC
    xor  eax, eax          ; eax = accumulator
    xor  r8d, r8d          ; r8d = index i = 0
.top:
    cmp  r8d, 4
    jge  .check
    movzx edx, byte ptr [rcx+r8]  ; edx = input[i]
    lea  r9d, [r8+1]              ; r9d = i+1 (weight)
    imul edx, r9d                 ; edx = input[i] * (i+1)
    add  eax, edx                 ; accumulate
    inc  r8d
    jmp  .top
.check:
    cmp  eax, 0x2E2        ; 738
    sete al
    movzx eax, al
    ret
check_password ENDP
```

What 4-character string passes the check?

---

## Answer

**`GOOD`**

Bytes: `G`=71, `O`=79, `O`=79, `D`=68.

- The loop computes a *positional-weighted sum*: `input[0]*1 + input[1]*2 + input[2]*3 + input[3]*4`, unlike a plain accumulator each byte's contribution scales with its index.
- Plugging in `GOOD`: `71*1 + 79*2 + 79*3 + 68*4 = 71+158+237+272 = 738 = 0x2E2`, matching the target, so `sete al` sets `eax=1`.
- To solve backward, pick any four bytes whose weighted sum hits 738 — the weights (1,2,3,4) mean many ASCII combinations work, `GOOD` is just one convenient solution.
