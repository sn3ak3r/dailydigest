# Reverse-a-function drill — 2026-09-25

Target: Windows x86-64 (MSVC calling convention: first int arg in `ecx`, return in `eax`).

Reverse this short function to equivalent C:

```asm
mystery:
    bsf     eax, ecx
    jnz     found
    mov     eax, -1
found:
    ret
```

What does `mystery(unsigned int x)` return?

---

## Answer

```c
int mystery(unsigned int x) {
    if (x == 0)
        return -1;
    for (int i = 0; i < 32; i++) {
        if (x & (1u << i))
            return i;
    }
    return -1; /* unreachable */
}
```

It returns the **bit index of the lowest set bit** in `x` (like `ffs(x) - 1`), or `-1` if `x` is zero.

## Explanation

- `bsf eax, ecx` (Bit Scan Forward) scans `ecx` from bit 0 upward and writes the index of the first `1` bit into `eax`; if the source is zero, the result is undefined and the zero flag (ZF) is set.
- `jnz found` skips the fallback only when `ecx` was nonzero (ZF clear), since `bsf` sets ZF when the input is all zeros.
- The `mov eax, -1` path handles the zero-input edge case explicitly, matching the classic "no bits set" sentinel returned by functions like `ffs`.
