# Crackme: find the input (Windows x64, arg in ecx)

```
48 63 C1       movsxd rax, ecx
48 83 C0 05    add rax, 5
48 C1 E8 20    shr rax, 32
83 F8 FF       cmp eax, -1
0F 94 C0       sete al
C3             ret
```

Which 32-bit value of `ecx` makes the function return 1? Give the largest one in hex.

---

**Answer:** `0xFFFFFFFA` (-6). Any `ecx` <= -6 works.

1. `movsxd` sign-extends ecx to 64 bits, so the `add` happens in 64 bits and cannot wrap at 32 bits.
2. `shr rax, 32` keeps only the upper half, which is 0xFFFFFFFF exactly when the 64-bit sum is negative, otherwise 0.
3. So the check is `ecx + 5 < 0`, i.e. ecx <= -6. Opcode `48 63` is MOVSXD (REX.W + 63), not the 32-bit `mov`.
