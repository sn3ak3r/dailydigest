# Decode-one-instruction drill — 2026-10-03

Target: Windows x86-64.

Decode this instruction (hex bytes):

```
31 C9
```

What is the assembly, and why do compilers emit it? What happens to `rcx`?

---

## Answer

`xor ecx, ecx`

- `31` = `XOR r/m32, r32`; ModRM `C9` = `11 001 001` → mod=11 (register-direct), reg=ecx, rm=ecx, so both operands are the same register.
- x ^ x = 0, so it zeroes `ecx` in 2 bytes (vs 5 for `mov ecx, 0`), and CPUs treat it as a dependency-breaking zero idiom.
- Writing a 32-bit register zero-extends into the upper half, so the whole of `rcx` becomes 0 — no REX.W needed.
