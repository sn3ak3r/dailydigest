# Reverse a Short Function to C (Windows x86-64)

Target: Windows x64 (first `int` argument arrives in `ecx`).

Reverse this disassembled function to equivalent C:

```asm
scale_value:
    mov     eax, ecx
    lea     eax, [rax + rax*4]
    ret
```

What C function does this compile to? Give the signature and body.

---

## Answer

```c
int scale_value(int x) {
    return x * 5;
}
```

## Explanation

- `mov eax, ecx` copies the incoming argument (`x`, passed in `ecx` per the
  Windows x64 calling convention) into `eax`, the register used to build
  and return the result.
- `lea eax, [rax + rax*4]` is not an address load here — it's a classic
  compiler trick that uses the LEA addressing-mode math (`base + index*scale`)
  to compute `rax + rax*4 = rax*5` in one instruction, avoiding a slower
  `imul`.
- The result is already in `eax` when `ret` executes, matching the x64
  convention of returning integers in `eax`/`rax`, so no extra move is
  needed before returning.
