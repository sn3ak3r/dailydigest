# Crackme: find the inputs (Windows x64, args in ecx and edx)

```
check:
    lea    eax, [rcx+rdx]
    cmp    eax, 100
    jne    fail
    mov    eax, ecx
    sub    eax, edx
    cmp    eax, 20
    jne    fail
    mov    eax, 1
    ret
fail:
    xor    eax, eax
    ret
```

`check(int a, int b)` takes two arguments. Which `a` (ecx) and `b` (edx) make it return 1?

---

**Answer:** `a = 60`, `b = 40`

1. Windows x64 passes the first integer arg in `ecx` and the second in `edx`; `lea eax, [rcx+rdx]` adds them into a third register without touching either input or the flags.
2. The two checks give `a + b == 100` and `a - b == 20`; any mismatch jumps to `fail`, where `xor eax, eax` returns 0.
3. Adding the equations gives `2a = 120`, so `a = 60`, then `b = 100 - 60 = 40` (check: 60 - 40 = 20).
