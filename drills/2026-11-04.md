# Reverse-a-function drill — 2026-11-04

Target: Windows x86-64 (arg in `ecx`).

Reverse this short function to equivalent C:

```asm
mystery:
    or      ecx, 1
    bsr     eax, ecx
    ret
```

What does it return for 0, 1, 2 and 1000? Why the `or`?

---

## Answer

```c
unsigned mystery(unsigned x) {
    x |= 1;
    return 31 - __builtin_clz(x);   // index of highest set bit = floor(log2(x))
}
```

Results: 0 → 0, 1 → 0, 2 → 1, 1000 → 9.

## Explanation

- `bsr` (0F BD) scans from bit 31 down and returns the index of the highest set bit, i.e. floor(log2(x)).
- With a zero source, `bsr` sets ZF and leaves the destination undefined, so `or ecx, 1` guarantees a nonzero input.
- Setting bit 0 never changes the highest set bit of a nonzero x, so only x = 0 is affected (it returns 0).
