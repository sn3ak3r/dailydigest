# 2026-09-09 — Decode One Instruction (Windows x86-64)

Decode this instruction (Intel syntax), byte by byte:

```
48 89 04 24
```

Give the mnemonic and full operands.

---

**Answer:** `mov qword ptr [rsp], rax`

**Explanation:**
- `48` is REX.W, forcing 64-bit operand size; `89` is `MOV r/m64, r64`, so a register goes into a memory operand or another register.
- ModRM `04` = `00 000 100`: mod=00 (no displacement), reg=000 (RAX, the source), rm=100 — this rm value doesn't name RSP directly, it's the escape code meaning "a SIB byte follows."
- SIB `24` = `00 100 100`: scale bits are unused, index=100 (the "no index" sentinel), base=100 (RSP). RSP can only appear as a memory base through this SIB detour, never via a bare ModRM rm field, so the final address is just `[rsp]` with `rax` stored into it.
