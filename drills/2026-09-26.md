# Mini Crackme: Find the Passing Input

Windows x86-64, `rcx` = pointer to a null-terminated C string. Find a string that makes `check` return 1.

```asm
check:                        ; rcx = string pointer, returns eax (1=pass, 0=fail)
    xor     eax, eax          ; eax = accumulator
    xor     edx, edx          ; edx = index
.loop:
    movzx   r8d, byte [rcx+rdx]
    test    r8d, r8d
    jz      .done
    movzx   r9d, byte [rcx+rdx+1]
    test    r9d, r9d
    jz      .done
    sub     r8d, r9d
    jns     .skip
    neg     r8d
.skip:
    add     eax, r8d
    inc     edx
    jmp     .loop
.done:
    cmp     eax, 0
    sete    al
    ret
```

What input(s) pass?

---

## Answer

Any string whose characters are all identical, e.g. `"aaaa"` (a single character, or even `""`, also passes).

```c
int check(const char *s) {
    int sum = 0;
    for (int i = 0; s[i] && s[i+1]; i++)
        sum += abs((int)s[i] - (int)s[i+1]);
    return sum == 0;
}
```

**Explanation:**
1. The loop walks adjacent character pairs `s[i]`/`s[i+1]`, stopping via two null-checks (`jz .done`) as soon as either byte is the terminator — this is a one-char lookahead, not a plain strlen scan.
2. `sub r8d, r9d` / `jns .skip` / `neg r8d` is a *branching* absolute-value idiom (contrast with the branchless `sar`/`xor`/`sub` trick): if the difference is negative, negate it.
3. Since each term added to `eax` is non-negative, the only way the total can equal zero is if every adjacent pair is equal — i.e. every character in the string is the same.
