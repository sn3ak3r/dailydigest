# Reverse-a-function drill — 2026-10-19

Target: Windows x86-64 (first arg in `rcx`; return in `eax`).

Reverse this short function to equivalent C:

```asm
mystery:
    movzx   eax, word ptr [rcx+4]
    movzx   edx, word ptr [rcx+6]
    imul    eax, edx
    add     eax, dword ptr [rcx+8]
    ret
```

`rcx` holds a pointer. What struct layout does the code imply, and what does `mystery` return?

---

## Answer

```c
struct S { int id; unsigned short w, h; int bias; };

int mystery(struct S *p) {
    return p->w * p->h + p->bias;
}
```

## Explanation

- `[rcx+off]` with a constant offset is a struct field access: offsets 0, 4, 6, 8 give an int at 0 (never read), two 16-bit fields at 4 and 6, and an int at 8.
- `word ptr` plus `movzx` means the fields are `unsigned short`, loaded and zero-extended to 32 bits before the multiply (a signed short would use `movsx`).
- `imul` multiplies w*h, then `add` takes `bias` straight from memory; the unread field at offset 0 is why offsets alone don't reveal the full struct.
