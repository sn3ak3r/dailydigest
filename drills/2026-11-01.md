# Reverse-a-function drill — 2026-11-01

Target: Windows x86-64 (args in `ecx`, `edx`).

Reverse this short function to equivalent C:

```asm
mystery:
    bt      ecx, edx
    setc    al
    movzx   eax, al
    ret
```

Which flag carries the result of `bt`, and why is `movzx` needed?

---

## Answer

```c
unsigned mystery(unsigned x, unsigned n) {
    return (x >> (n & 31)) & 1;   // is bit n of x set?
}
```

## Explanation

- `bt ecx, edx` copies bit number `edx` of `ecx` into the carry flag (CF) and changes nothing else, so no shift or mask is needed.
- `setc al` writes only the low byte (0 or 1), so `movzx eax, al` clears the upper bits and returns a clean 32-bit int.
- With a register operand the bit index is taken mod 32, so `n = 33` tests bit 1.
