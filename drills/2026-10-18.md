# Decode-one-instruction drill — 2026-10-18

Target: Windows x86-64.

Decode this instruction:

```
0F B6 04 11
```

What is the assembly? Why is there no REX prefix, and what size is the memory read versus the register written?

---

## Answer

`movzx eax, byte ptr [rcx+rdx]`

- `0F` is the two-byte opcode escape; `0F B6` = MOVZX r32, r/m8. ModRM `04` = `00 000 100`: mod=00 (no disp), reg=000 (eax, the destination), rm=100 (a SIB byte follows).
- SIB `11` = `00 010 001`: scale=1, index=rdx, base=rcx. Addresses are 64-bit by default, so no REX is needed.
- Only 1 byte is read from memory; it is zero-extended into eax, and the 32-bit write also clears the upper half of rax.
