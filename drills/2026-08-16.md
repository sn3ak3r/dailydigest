# Drill: 2026-08-16 — Reverse a Short Function

Target: Windows x86-64 (first integer arg in `ecx`). Reverse this
function to equivalent C.

```asm
func:
    xor     eax, eax
    xor     r8d, r8d
.loop:
    mov     edx, r8d
    imul    edx, edx
    add     eax, edx
    inc     r8d
    cmp     r8d, ecx
    jl      .loop
    ret
```

What does `func` compute, in terms of its single parameter?

---

## Answer

```c
int func(int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += i * i;
    }
    return sum;
}
```

**Explanation:**
`eax` (return value) and `r8d` (loop counter `i`) are both zeroed before
the loop starts. Each iteration computes `i*i` into `edx` via `imul edx,
edx`, adds it into the running total `eax`, then `inc r8d` / `cmp r8d,
ecx` / `jl .loop` implements `for (i = 0; i < n; i++)` — comparing the
counter against `ecx`, the Windows x64 first-argument register `n`,
and looping while it's still less. The function returns the sum of
squares from `0` to `n-1`.
