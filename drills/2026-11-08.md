# Crackme: find the input (Windows x64, arg in ecx)

```
    movsx  eax, cl
    add    eax, 100
    cmp    eax, 95
    sete   al
    movzx  eax, al
    ret
```

Which low byte of `ecx` (`cl`) makes the function return 1? Give it as a hex byte. (Upper bits of `ecx` are arbitrary.)

---

**Answer:** `0xFB` (251 unsigned, -5 signed)

1. `movsx eax, cl` (0F BE /r) sign-extends the byte to 32 bits, copying bit 7 into bits 8-31; only `cl` matters, the rest of `ecx` is ignored.
2. The check needs `sext(cl) + 100 == 95`, so `sext(cl) = -5`.
3. -5 as a byte is 0xFB, and sign-extending it gives 0xFFFFFFFB, so 0xFB works (check: -5 + 100 = 95). Zero-extension (`movzx`) would make this impossible.
