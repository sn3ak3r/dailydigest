# Crackme drill: find the passing input

Windows x64, `ecx` holds your 32-bit integer argument. The function returns 1 for the correct input:

```
imul eax, ecx, 7
not  eax
cmp  eax, 0FFFFFFA4h
sete al
ret
```

What value of `ecx` returns 1?

---

**Answer: 13**

1. `imul eax, ecx, 7` is the three-operand form: eax = ecx * 7 (destination, source, immediate), leaving ecx intact.
2. `not` flips every bit, so ~y = -y - 1. The constant 0xFFFFFFA4 is -92 signed, so -y - 1 = -92 and y = 91.
3. 7x = 91 gives x = 13. Check: 13*7 = 91 = 0x5B, and ~0x5B = 0xFFFFFFA4.
