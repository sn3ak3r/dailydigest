# Daily Drill — 2026-08-26 (mini crackme)

Target: Windows x86-64, fastcall (first int arg in `ecx`).

A "license check" function takes one byte (a character) in `cl` and
returns 1 (pass) or 0 (fail). Find the single-character input that
makes it return 1.

```asm
check_char:
        mov     eax, ecx        ; eax = input char
        not     eax             ; bitwise complement (all 32 bits)
        and     eax, 0FFh       ; keep only the low byte
        cmp     eax, 0B4h       ; compare against target
        jne     fail
        mov     eax, 1
        ret
fail:
        xor     eax, eax
        ret
```

What single ASCII character passed in `cl` makes `check_char` return 1?

---

## Answer

**`'K'`** (0x4B / decimal 75)

1. `not eax` flips every bit of the 32-bit register, so if `ecx` holds
   the input byte `c`, after `not` the low byte becomes `(~c) & 0xFF`
   (upper bits get masked off next anyway).
2. The check requires `(~c) & 0xFF == 0xB4`. Solve backward: invert
   the target — `~0xB4 & 0xFF = 0x4B` — since NOT is its own inverse.
3. `0x4B` is ASCII `'K'`. Feeding `'K'` in `cl` makes `eax` land on
   `0xB4`, the `jne` falls through, and the function returns 1.
