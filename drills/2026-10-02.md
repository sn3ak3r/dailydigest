# Mini crackme: 2026-10-02

Windows x64 calling convention. `check(unsigned i)` receives `i` in ECX and returns 1 in AL if accepted. `table` is a read-only byte array in `.rdata`: `04 0B 09 0A 07`.

```
check:
  cmp  ecx, 4
  ja   fail
  lea  rdx, [rip+table]
  movzx eax, byte ptr [rdx+rcx]
  add  eax, ecx
  cmp  eax, 13
  sete al
  ret
fail:
  xor  eax, eax
  ret
```

What value of `i` makes `check` return 1?

---

**Answer: i = 3**

1. `ja` is an unsigned compare, so only i = 0..4 reach the table read (any negative int looks huge and fails). `lea rdx,[rip+table]` loads the table's address; `[rdx+rcx]` indexes it.
2. The check is table[i] + i == 13, giving sums 4, 12, 11, 13, 11 for i = 0..4.
3. Only i = 3 works (table[3] = 0x0A, 10 + 3 = 13).
