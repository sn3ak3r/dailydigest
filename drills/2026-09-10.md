# Reverse a Function — 2026-09-10

Target: Windows x86-64. `rcx` = first arg, `edx` = second arg (32-bit), `eax` returns nothing (void).

```asm
reverse:
    xor     eax, eax          ; i = 0
    lea     r8d, [edx-1]      ; j = n-1
.loop:
    cmp     eax, r8d
    jge     .done
    mov     r9d,  [rcx+rax*4] ; tmp = arr[i]
    mov     r10d, [rcx+r8*4]  ; arr[j]
    mov     [rcx+rax*4], r10d ; arr[i] = arr[j]
    mov     [rcx+r8*4], r9d   ; arr[j] = tmp
    inc     eax
    dec     r8d
    jmp     .loop
.done:
    ret
```

What C function does this implement? Write the equivalent source.

---

## Answer

```c
void reverse(int *arr, int n) {
    int i = 0, j = n - 1;
    while (i < j) {
        int tmp = arr[i];
        arr[i] = arr[j];
        arr[j] = tmp;
        i++;
        j--;
    }
}
```

**Explanation:**
1. `rcx`/`edx` are the Windows x64 integer args, so `rcx` is `int *arr` and `edx` is `int n`; `eax`/`r8d` are scratch locals `i` and `j = n-1`.
2. Each iteration swaps `arr[i]` and `arr[j]` through `r9d`/`r10d` as the `tmp` variable, using `rax*4`/`r8*4` scaled-index addressing for the two `int` array slots.
3. `cmp eax, r8d` / `jge .done` is the loop guard `while (i < j)`, and `inc eax` / `dec r8d` converge the two pointers each pass — a classic in-place array-reversal idiom.
