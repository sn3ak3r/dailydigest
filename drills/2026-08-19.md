# Drill: 2026-08-19 — Reverse a Short Function to C

Target: Windows x86-64 (fastcall: first two `int` args in `ecx`, `edx`; return in `eax`).

Reverse this disassembly to equivalent C:

```asm
foo:
    cmp     ecx, edx
    cmovle  ecx, edx
    mov     eax, ecx
    ret
```

What does `foo(int a, int b)` compute?

---

## Answer

```c
int foo(int a, int b) {
    if (a <= b) {
        a = b;
    }
    return a;
}
```

Equivalently: `return (a > b) ? a : b;` — this is `max(a, b)`.

**Explanation:**
1. `cmp ecx, edx` sets flags for `ecx - edx` (i.e. `a - b`), without altering either register.
2. `cmovle ecx, edx` is a conditional move: it copies `edx` into `ecx` only if the *previous* compare's flags indicate "less than or equal" (`a <= b`), replacing a branch with data flow — no jump is taken either way.
3. `mov eax, ecx` places the (possibly updated) `ecx` into the return register, so the function returns whichever of `a`/`b` is larger.
