# Decode-one-instruction drill — 2026-11-06

Target: Windows x86-64.

Decode this instruction:

```
C6 41 03 41
```

What is the assembly? Which operand is the immediate, and how many bytes does it write?

---

## Answer

`mov byte ptr [rcx+3], 0x41`

- `C6 /0 ib` is MOV r/m8, imm8. ModRM `41` = `01 000 001`: mod=01 (disp8 follows), reg=000 (the /0 opcode extension, not a register), rm=001 (rcx base). Then `03` = disp8, `41` = imm8.
- The immediate always comes last, after the displacement. It writes exactly one byte ('A') to rcx+3; neighbouring bytes are untouched.
- In C: `((char*)p)[3] = 'A';` with p in rcx (Windows x64 first argument).
