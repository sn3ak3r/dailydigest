# Mini Crackme — 2026-08-29 (Windows x86-64)

`rcx` holds a pointer to a null-terminated ASCII string (Windows x64 calling
convention, first arg in `rcx`). Find a string that makes `check` return 1.

```asm
check:
    xor     eax, eax          ; eax = accumulator
    xor     edx, edx          ; edx = index
.loop:
    movzx   r8d, byte [rcx+rdx]
    test    r8d, r8d
    jz      .done
    add     eax, r8d          ; acc += current byte
    shl     eax, 1            ; acc <<= 1
    inc     edx
    jmp     .loop
.done:
    cmp     eax, 0x188
    sete    al
    movzx   eax, al
    ret
```

What string makes `check` return 1?

---

## Answer: `"AB"`

Each loop iteration folds a byte into the accumulator with `acc = (acc + c) << 1`
— a base-2 Horner scheme, so later characters get shifted further left than
earlier ones.

Tracing `"AB"` (0x41, 0x42): `acc = 0`, then `(0+0x41)<<1 = 0x82`, then
`(0x82+0x42)<<1 = 0x188`, matching the target — the null terminator then
exits the loop without touching `acc`.

Any two-byte string `c0 c1` with `(c0<<1 + c1)<<1 == 0x188` also passes, so
`"AB"` is one of several valid solutions, not the only one.
