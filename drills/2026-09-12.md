# 2026-09-12 — Decode One Instruction (Windows x86-64)

Decode this instruction (Intel syntax), byte by byte:

```
4A 8B 04 63
```

Give the mnemonic and full operands.

---

**Answer:** `mov rax, qword ptr [rbx + r12*2]`

**Explanation:**
- `4A` = REX `0100 1010`: W=1 (64-bit operands), X=1, B=0. `8B` is `MOV r64, r/m64` (memory/register into register).
- ModRM `04` = `00 000 100`: mod=00 (no displacement), reg=000 (RAX, the destination), rm=100 — the SIB-follows escape code.
- SIB `63` = `01 100 011`: scale=01 (×2), index=100, base=011 (RBX). An index of 100 normally means "no index," but REX.X=1 extends that 3-bit field to `1100` = R12, making it a real scaled index rather than the no-index sentinel — the same detour used for RSP-as-base extends here to select R12 as an index register.
