# Reverse-a-function drill — 2026-11-13

Target: Windows x86-64 (arg in `ecx`).

Reverse this short function to equivalent C:

```asm
mystery:
    xor     eax, eax
    jmp     check
top:
    mov     edx, ecx
    dec     edx
    and     ecx, edx
    inc     eax
check:
    cmp     ecx, 0
    jne     top
    ret
```

What does it return for 0, 1, 12 and 0xFF?

---

## Answer

```c
int mystery(unsigned x) {
    int n = 0;
    while (x != 0) {
        x &= x - 1;   // clear lowest set bit
        n++;
    }
    return n;          // popcount: number of 1 bits
}
```

Results: 0, 1, 2, 8.

## Explanation

- `jmp check` jumps straight to the test at the bottom, so the body can run zero times. That makes it a `while` loop, not `do/while`. Compilers often lay loops out this way.
- `dec` subtracts 1 (`inc` adds 1). x-1 flips the lowest set bit and every 0 below it, so `x & (x-1)` clears exactly that one bit. For 12 (1100b): 1100 → 1000 → 0, two passes.
- eax counts the passes, so the result is the number of set bits.
