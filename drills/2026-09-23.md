# Mini Crackme (2026-09-23)

Target: Windows x86-64 (MSVC calling convention: RCX = pointer to a
null-terminated ASCII string). Find an input string that makes `check`
return 1.

```asm
check:
        xor     r8d, r8d        ; r8d = length counter
        xor     r9d, r9d        ; r9d = sum accumulator
.loop:
        movzx   eax, byte ptr [rcx + r8]
        test    eax, eax
        jz      .end
        add     r9d, eax
        inc     r8d
        jmp     .loop
.end:
        cmp     r8d, 5
        jne     .fail
        cmp     r9d, 500
        jne     .fail
        mov     eax, 1
        ret
.fail:
        xor     eax, eax
        ret
```

What string(s) satisfy `check`?

---

## Answer

`"ddddd"` (five copies of the character `'d'`) passes.

- The loop walks the string until the null terminator, counting bytes
  into `r8d` and summing their ASCII values into `r9d` — so `check`
  requires exactly two things: length `== 5` and byte-sum `== 500`.
- `'d'` is ASCII `0x64` = 100 decimal, so five `'d'` characters give
  length 5 and sum `5 * 100 = 500`, satisfying both comparisons.
- Any other 5-character string whose bytes sum to 500 also works (e.g.
  `"cdddd"` shifted by ±1 elsewhere), since the check only constrains
  the total, not individual characters.
