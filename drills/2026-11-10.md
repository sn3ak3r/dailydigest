# Reverse-a-function drill — 2026-11-10

Target: Windows x86-64 (arg in `ecx`).

Reverse this short function to equivalent C:

```asm
mystery:
    mov     eax, ecx
    cdq
    xor     eax, edx
    sub     eax, edx
    ret
```

What does it return for 5, -5, 0 and -2147483647?

---

## Answer

```c
int mystery(int x) {
    return x < 0 ? -x : x;   // branchless abs()
}
```

Results: 5, 5, 0, 2147483647.

## Explanation

- `cdq` (opcode 99) sign-extends eax into edx: edx = 0 for x >= 0, or 0xFFFFFFFF (-1) for x < 0, i.e. the sign mask.
- For negative x, `xor` with -1 gives ~x and `sub` of -1 adds 1, so ~x + 1 = -x (two's-complement negate). For non-negative x both steps do nothing.
- No branch is needed. INT_MIN (0x80000000) stays negative, since +2^31 doesn't fit in an int.
