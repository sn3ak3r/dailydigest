# Mini Crackme — 2026-09-08 (Windows x86-64)

`cl` holds a single input byte (Windows x64 calling convention, first
arg in `cl`). Find the value of `cl` that makes `check` return 1.

```asm
check:
    movzx   eax, cl         ; zero-extend the input byte
    cmp     eax, 0x41       ; below 'A'?
    jl      fail
    cmp     eax, 0x5A       ; above 'Z'?
    jg      fail
    sub     eax, 0x14       ; shift the value down by 20
    cmp     eax, 0x3D       ; compare to target
    jne     fail
    mov     eax, 1
    ret
fail:
    xor     eax, eax
    ret
```

What value of `cl` makes `check` return 1?

---

## Answer: `cl = 'Q'` (0x51)

The two `cmp`/`jl`/`jg` pairs bound `cl` to the uppercase-letter range
`0x41`-`0x5A` before anything else runs — any byte outside `'A'`-`'Z'`
takes the `fail` branch immediately.

Working backward from the final check: `eax - 0x14 == 0x3D` means
`eax` must be `0x3D + 0x14 = 0x51` right before the `sub`.

`0x51` is `'Q'`, and it already sits inside the `0x41`-`0x5A` range
checked earlier, so both bounds checks fall through, the subtraction
and comparison match, and `check` returns 1.
