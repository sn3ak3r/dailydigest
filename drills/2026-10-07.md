# Reverse-a-function drill — 2026-10-07

Target: Windows x86-64 (arg in `ecx`, return in `eax`).

Reverse this short function to equivalent C:

```asm
mystery:
    xor     eax, eax
    test    ecx, ecx
    je      done
again:
    lea     edx, [rcx-1]
    inc     eax
    and     ecx, edx
    jne     again
done:
    ret
```

What does `mystery(unsigned x)` compute? What does `and ecx, edx` do each pass?

---

## Answer

```c
int mystery(unsigned x) {
    int n = 0;
    while (x) { x &= x - 1; n++; }
    return n;
}
```

Population count (number of set bits), Kernighan style.

## Explanation

- `lea edx,[rcx-1]` is just subtraction (no memory access); `x & (x-1)` clears the lowest set bit, so each loop pass removes exactly one 1-bit.
- `and` sets ZF itself, so the `jne` needs no separate `test`; the loop ends when `x` hits 0, and the up-front `test/je` handles `x == 0` returning 0.
- Iterations = number of set bits, so `mystery(0xF0F0)` = 8.
